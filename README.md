# 🎮 Bit&Rust Launcher

O Bit&Rust Launcher é um launcher desktop gamer desenvolvido com Electron.js, focado em criar uma experiência estilo console para jogos de PC, Steam e retro games.

A aplicação integra biblioteca Steam, executáveis locais, RetroArch, ROMs e navegação por controle/gamepad em uma interface fullscreen moderna inspirada em consoles.

## ✨ Principais recursos

- 🎮 Interface estilo console em fullscreen
- 🕹 Navegação completa por controle/gamepad
- ☁️ Integração com Steam Web API
- 📦 Importação automática da biblioteca Steam
- 🔥 Detecção de jogos instalados e não instalados
- 🧩 Suporte a executáveis locais
- 👾 Integração com RetroArch e ROMs
- 🧠 Nome customizado para ROMs
- 🌐 Web App interno (YouTube/Google)
- 👤 Sistema de usuários locais
- 🏆 Integração com RetroAchievements
- 🎨 Sistema de temas e configurações
- 💾 Persistência local em SQLite
- 🐧 Build para Linux AppImage/Deb
- 🪟 Build para Windows (.exe)

## 🛠 Tecnologias

- Electron.js
- Node.js
- SQLite
- HTML/CSS/JavaScript
- Bootstrap
- Steam Web API
- RetroAchievements API

## 🎯 Objetivo

O projeto busca transformar o PC em uma experiência semelhante a um console moderno, centralizando jogos Steam, emuladores e aplicações em uma única interface otimizada para controle.
